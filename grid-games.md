# Grid games — the opt-in game-logic packs

A family of headless, seeded, **logic-only** game components, each its own artifact
(games that don't use one never load it). They share the match3 doctrine: instant
logic, deterministic from a `seed`, an ordered event journal or result object the game
presents at its own pace, and a self-play surface (`findMoves`/`autoplay`) so a game
can test itself. See [match3.md](match3.md) and [match3-variants.md](match3-variants.md)
for the swap-matching family; this doc maps the rest.

Each imports from its own path, e.g.:
```js
import { createPlacer } from '../engine/packs/placer.js'; // its own artifact — not in webgpu.js
```

## packs/placer — tray placement (1010!, Block Blast, Woodoku)

`createPlacer({ cols, rows, seed, regions?, pieces?, traySize? })`. Drag tray pieces
onto a static board; completed **regions** (rows + columns by default; add
`sudokuBoxes()` for the nine 3×3 Woodoku boxes — regions are just `{id, cells}` data)
clear simultaneously with no gravity. `place(pieceId, at)` → `{steps, combo, streak,
gameOver}`; `canPlace`, `findPlacements` (scored, best-first), `autoplay`. **Game over
runs after every placement** (mid-tray) — if no tray piece fits anywhere, it ends.
`PIECES_1010` / `PIECES_BLOCKS` exported. Streak = consecutive clearing placements;
combo = regions cleared at once (steep multi-region score curve).

## packs/slide — directional slide-merge (2048, Threes)

`createSlide(config2048())` or `createSlide(configThrees())` — two configs of one
resolver. `move(dir)` → `{valid, moves:[{id,from,to}], merges:[{intoId,goneId,value,at}],
spawn, gained, gameOver}`; the result IS the journal (slide → pop → spawn). Key rules
baked in: **merge-once-per-move** (`[2,2,4]→[4,4]`, wall-side pair wins in `[4,4,4]`)
and **illegal-move rejection** (nothing moved → no spawn, no turn). `step: 'full'` (2048)
vs `'one'` (Threes); spawn policy `anyEmpty`/`oppositeEdge` × `weighted`/`bag`; `peek()`
for the Threes preview; `legalMoves`, `autoplay`.

## packs/reveal — Minesweeper

`createMinefield({ cols, rows, mines, seed, firstClickSafe: 'area' })`. Hidden state:
the board knows all, `cell(x,y)` shows the mask. `reveal(x,y)` → `RevealResult` whose
`waves` are **distance-ordered** (ripple the flood outward). Mines placed on first
click (excluding its 3×3). `flag` (cycle), `chord` (reveal a satisfied number's rest;
a wrong flag detonates), `hint()` (provably-safe + provably-mine cells, also the
autoplay driver), `step()` (one deduction). Win = all non-mine cells revealed.

## packs/deduce — three logic games, solvable by construction

- `createNonogram({cols, rows, seed})` — Picross. `rowClues/colClues`, `set(x,y,mark)`,
  `lineSatisfied`, `solved` (clue-satisfaction, allows alternate solutions),
  `solveStep()` (one forced deduction). Generation rejects puzzles the line-solver
  can't finish → every puzzle is logic-solvable.
- `createLightsOut({cols, rows, seed, stamp?, wrap?})` — `press(x,y)` (returns toggled
  cells), `solved`, `solution()` (GF(2) minimal press-set). **Generated by scrambling
  from solved** → always solvable on any size/stamp/topology.
- `createFlood({cols, rows, colors, seed})` — Flood-It. `pick(color)` returns
  ring-ordered absorption waves, `preview(color)` (cells gained), `findMoves`,
  `moveLimit` (bot-calibrated).

## packs/faller — the falling-piece family (Tetris, Puyo, Columns, Dr. Mario)

`createWell({ cols, rows, seed, pieces, rotation, match, gravity })` — one well, three
plug points. `pieces`: `'tetromino'|'columns'|'puyo'|'capsule'`; `rotation`:
`'srs'|'cycle'|'orbit'|'none'` (SRS kick tables + I-piece table included); `match`:
`'rows'|{lines,diagonals}|{flood:N}`. Deterministic tick logic — the **game owns real
time** and calls `tick()`; also `shift`, `rotate` (with wall kicks), `softDrop`,
`hardDrop`, `hold`, `ghost()`. 7-bag randomizer, lock-delay with move-reset cap,
T-spin 3-corner detection, `viruses` (Dr. Mario static targets), `findPlacements` +
`place(x,state)` + `autoplay` (the flat-stacking AI). `TickResult.steps` is the journal
(spawn/move/rotate/lock/match/clear/fall).

## packs/pusher — Sokoban (+ the shared undo service)

`createPusher({ level })` parses the standard XSB format (`# $ . * + @`). `move(dir)` →
`{moved, pushed, ontoDeadSquare, solved}`; **unbounded `undo`/`redo`** (undo pulls a box
back); `metrics` (moves + pushes); `deadSquares()`/`isDead` (precomputed by reverse-
pulling from goals); `isFrozen`; `solve(maxNodes)` (BFS solver for hints/autoplay).
Also `createHistory({apply, revert})` — the reusable unbounded undo/redo stack.

## packs/flow — edge-mask tiles (Netwalk, Pipe Mania)

`createFlowGrid({ cols, rows, seed, wrap? })`. Tiles are 4-bit edge masks (`UP RIGHT
DOWN LEFT`). Netwalk: `generateNet()` (carve a spanning tree from the server, scramble
rotations → always solvable), `rotate(x,y,steps)`, `connectivity()` (the lit network),
`solved`, `solveNet()` (rotation plan), `lock`. Pipe Mania: `startPipes(queue, start,
dir)`, `placePipe`, `advanceFlow()` (fluid advances one segment on the game's clock).

## packs/gridsim — the cellular tick (Boulder Dash, Chip's tiles, Snake)

`createGridSim({ level, legend?, quota? })` — a deterministic top-left→bottom-right scan,
one pass per `tick()` (one tick = one beat). Ships `BOULDERDASH_LEGEND` (falling/rolling
boulders, diamonds, firefly/butterfly wall-followers, butterfly→diamond explosions) and
a Kind interface (`rounded/falls/consumable/onEnter/blocksEdge…`) for the Chip's tile
vocabulary. `input(dir)`, `tick()` → `{moves, explosions, collected, dead, exited}`,
`autoInput()` (greedy diamond pilot). **Snake** is a citizen: `createSnake({cols, rows,
seed, wrap})` — deque body + growth + 2-deep input buffer with the two classic edge
cases (tail-cell entry legal unless growing; 180° reversal checked vs the last-used dir).

## packs/shooter — Puzzle Bobble (offset-hex, connectivity-support)

`createBubbleField({ cols, rows, seed, colors, radius })`. Offset-hex grid; `aim(angle)`
(ray with wall reflections → snap cell), `shoot(angle, color?)` → `ShotResult`
(flight path, snap, pops, **drops** — the orphan-drop pass runs every resolution: pop
same-colour 3+, then flood from the ceiling and drop everything unreached). `liveColors`
(shots draw only from these), `findShots` (drop-weighted AI), `autoplay`.

## packs/rail — Zuma (marbles on a spline)

`createRail({ path, seed, colors, spacing, feedCount })` — the board is a 1-D ordered
list along a `PathSampler` (`linePath`/`polyPath` provided; the engine's Track fits).
`advance(dist)` pushes toward the skull, `insert(s, color)` wedges a shot and resolves:
pop 3+, then the gap closes and **rejoining ends chain-react** (`rejoinPops`). `posOf`,
`findShots`, `autoplay`, `won`.

## Match3 extensions (in packs/match3)

- **A1 operators**: `board.rotate(at, 'cw')` (2×2 twist), `board.shiftRow/shiftColumn`
  (wraparound slide), `swapAnywhere` config (Pokémon Shuffle). `operatorFreeMove` makes
  operators legal without a match (Bejeweled Twist). New steps `rotate`/`shift`.
- **A2 place-merge**: `createPlaceMerge({cols, rows, maxTier})` — Triple Town. `place(at)`
  merges 3+ connected equal (type,tier) into the next tier at the cell and cascades;
  walkers (bears) roam each turn and become tombstones when enclosed; `store()`,
  `findPlaces`, `autoplay`.
- **A3 rise**: `createRiseBoard({cols, rows, colors, fillRows})` — Panel de Pon. `rise()`
  (game-clock driven), `swap(a,b)` (horizontal, no-match-needed), chains from **fall
  provenance** (`chainFlag`), `addGarbage` + adjacent-match conversion, `findMoves`.
- **A4 versus**: `createVersus({attack, receive, maxPerDelivery, timing})` — the shared
  attack→**offset**→deliver pipe. `send(id, result)` offsets against the sender's own
  pending first; `pending(id)` (HUD meter); `deliver(id)` (capped garbage).
